Programmatic access to your dataset statistics
Login required
Base URL
{{ request.host_url.rstrip('/') }}
GET /api/dataset/<id>/stats

Returns descriptive statistics for all numeric columns in the specified dataset. The dataset must belong to the authenticated user's session.

Path Parameter
NameTypeDescription
idintegerDataset ID (visible in the URL when viewing a dataset)
Response Schema
{
  "dataset": "string",
  "rows":    integer,
  "columns": integer,
  "stats": {
    "<column_name>": {
      "mean":   float,
      "median": float,
      "std":    float,
      "min":    float,
      "max":    float,
      "nulls":  integer
    }
  }
}
Example Response
{
  "dataset": "Customer Churn",
  "rows":    7043,
  "columns": 21,
  "stats": {
    "tenure": {
      "mean":   32.3711,
      "median": 29.0,
      "std":    24.5595,
      "min":    0.0,
      "max":    72.0,
      "nulls":  0
    }
  }
}
